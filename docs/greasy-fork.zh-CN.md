从 X 左侧“私信”徽标、网页标题未读数字和标签页图标提醒中排除 Grok Bot，保留普通私信、其他通知和 bot 聊天列表的未读蓝点。

## 使用

1. 安装 Tampermonkey，并在扩展详情中开启“Allow User Scripts / 允许用户脚本”。
2. 点击本页“安装此脚本”，检查运行范围仅为 `https://x.com/*`，确认安装。
3. 刷新 X。脚本仅在 `x.com` 运行。

点击安装后若只显示源码，可下载 `.user.js`，在 Tampermonkey 的 Utilities → Import from file 中导入，已在 Brave 实测。如果扩展站点访问只允许 `x.com`，直接安装和自动更新可能受阻；需要自动更新时可按提示允许下载域名 `update.greasyfork.org`，或保持现有权限并手动导入新版。

## 范围与数据

- 调整“私信”导航徽标、标题数字及网站图标提醒。只有 bot 未读时，`(3) X` 变为 `X`，图标恢复普通样式；普通私信和其他通知仍保留提醒。不控制系统推送、手机通知或系统 App 徽标，不作用于 X 手机 App。
- 只排除 X 的 Grok Bot 会话，不识别普通 X 账号是否由真人运营。
- 脚本无网络请求、外部运行依赖、持久化存储或日志；读取页面现有的普通私信计数及原生标题组件已计算的未读计数，不读取消息正文、通知条目、Cookie 或认证信息，不标记已读，不调用或改写原生组件方法。切换图标时浏览器可能加载 X 的普通图标资源。
- 已验证 macOS Brave + Tampermonkey 5.5.1。其他浏览器和管理器暂未实测。
- 16 项自动测试通过，包含混合计数、其他通知保留及标题、图标恢复；真实真人消息到达链路尚未验收。
- X 改版或计数字段不可用时保留原生提醒。停用脚本并刷新即可恢复。
