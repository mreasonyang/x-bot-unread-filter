从 X 左侧“私信”未读徽标中排除 Grok Bot，保留普通私信提醒和 bot 聊天列表的未读蓝点。

## 使用

1. 安装 Tampermonkey，并在扩展详情中开启“Allow User Scripts / 允许用户脚本”。
2. 点击本页“安装此脚本”，检查运行范围仅为 `https://x.com/*`，确认安装。
3. 将 Tampermonkey 站点访问限制为 `x.com`，刷新 X。

## 范围与数据

- 只调整“私信”导航徽标，不控制系统通知、手机推送或浏览器标签页标题，不作用于 X 手机 App。
- 只排除 X 的 Grok Bot 会话，不识别普通 X 账号是否由真人运营。
- 脚本无网络请求、外部运行依赖、持久化存储或日志；只读取页面现有的普通私信计数字段并修改徽标，不读取消息正文、Cookie 或认证信息，不标记已读。
- 已验证 macOS Brave + Tampermonkey 5.5.1。其他浏览器和管理器暂未实测。
- 普通私信与 bot 混合计数通过自动测试；真实真人消息到达链路尚未验收。
- X 改版或计数字段不可用时保留原生提醒。停用脚本并刷新即可恢复。
