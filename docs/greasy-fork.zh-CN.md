在 `x.com` 桌面网页中，将 **Grok Bot 会话**的未读数从**左侧导航栏“私信”徽标**、**浏览器标签页标题未读数字**和**网站图标（favicon）未读红点**中排除，同时保留普通私信、其他通知以及聊天列表内 Bot 会话的未读蓝点。

例如当前仅有 3 条 Grok Bot 未读时，网页标题会从 `(3) X` 变为 `X`，标签页图标也会恢复为普通图标；有普通私信或其他通知未读时则正常显示提醒。

## 安装与使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 官方扩展，并在浏览器扩展管理详情中开启 **Allow User Scripts（允许用户脚本）**（Chromium 系浏览器见 [官方说明 Q209](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)，无需关闭浏览器安全防护）。
2. 点击本页安装按钮，确认运行范围仅为 `https://x.com/*` 后完成安装。
3. 刷新 `x.com` 即可生效。若需恢复 X 原生显示，在 Tampermonkey 中停用或删除本脚本后刷新 `x.com` 即可。

- **0.0.1–0.0.3 旧版用户升级注意**：`0.0.4` 更新了默认 `@name` 以在本站默认中文页面正确显示新标题。由于脚本管理器通过 `@name` + `@namespace` 识别安装条目（[平台说明](https://greasyfork.org/en/help/meta-keys)），已安装 `0.0.1`–`0.0.3` 的用户请直接在 Tampermonkey 编辑器内用 `0.0.4` 源码替换保存原有脚本（已在 Brave 实测保留单一路径与条目），或先删除旧版条目后再安装 `0.0.4`，以免产生重复脚本。新用户直接按正常步骤安装即可。
- **点击安装只显示源码时**：请下载 `.user.js` 文件，在 Tampermonkey 的 **Utilities → Import from file（从文件导入）** 中手动导入（已在 Brave 实测）。
- **站点访问权限与更新**：若把 Tampermonkey 的站点访问权限限制为仅 `x.com`，直接安装和自动更新可能受阻。你可保持现有权限并手动导入新版，或在提示时放行 `update.greasyfork.org`。GitHub 源码与双语说明会定期自动同步至本页（无固定间隔；跨版本/改名自动升级尚未实测）。

## 范围、隐私与兼容性

- **仅排除 Grok Bot，不识别“真人”**：只过滤 X 的 Grok Bot 会话未读数，不判断普通 X 账号背后是否为真人、自动回复或垃圾私信；普通账号私信一律按普通私信计入。
- **仅限桌面网页展示**：仅作用于 `x.com` 桌面网页，不影响 X 手机 App、系统推送或系统应用角标；不会标记已读、静音通知或删除消息。
- **隐私与安全回退**：读取页面现有的普通私信独立计数与原生标题组件已选定的未读计数，不读取私信正文、通知条目、Cookie 或认证信息，不调用或替换原生组件方法，无网络请求、外部依赖、持久化存储或日志（切换图标时浏览器可能加载 X 的普通图标资源）。若 X 改版导致预期计数字段不可用，脚本会自动保留或恢复原生提醒；不认识的标题格式和图标地址保持原样。
- **验证状态**：已在 macOS Brave 桌面版 + Tampermonkey 5.5.1 实测（含安装、编辑器内替换升级、刷新、页面切换、仅 Bot 未读过滤及提醒恢复），并通过 24 项自动化测试（含普通私信与 Bot 混合计数、其他通知保留）；真实普通私信在线新到达链路、跨版本/改名自动升级及其他浏览器/管理器尚未实测。
